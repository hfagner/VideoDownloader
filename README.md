## 🚀 Como Instalar

A instalação é feita através de um único arquivo executável que configurará tanto o motor local (backend) quanto os arquivos da extensão para o navegador.

### Passo 1: Instalar o Motor Local

1. Baixe o instalador: Acesse a pasta `dist` neste repositório e baixe o arquivo **`EdgeVideoDownloaderSetup.exe`**.
2. Execute o instalador no seu Windows. 
3. Siga o assistente de instalação. Ele irá configurar automaticamente o backend e criar um atalho chamado **"Motor Local - Edge Video Downloader"** na sua Área de Trabalho.
4. **IMPORTANTE:** Na última tela da instalação, o assistente mostrará o caminho onde a extensão foi salva. Use o botão **"Copiar caminho"** para facilitar o Passo 2.

### Passo 2: Configurar a Extensão no Microsoft Edge

1. Abra o navegador **Microsoft Edge**.
2. Na barra de endereços, digite `edge://extensions` e pressione Enter.
3. No menu lateral esquerdo (ou canto superior direito), ative a opção **"Modo de desenvolvedor"** (Developer mode).
4. Clique no botão **"Carregar sem compactação"** (Load unpacked).
5. Na janela de seleção de pastas, **cole o caminho** que você copiou no final da instalação (exemplo: `%LOCALAPPDATA%\EdgeVideoDownloader\extension`) e clique em "Selecionar Pasta".
6. Pronto! A extensão aparecerá ativada no seu navegador e você já pode começar a utilizar.
